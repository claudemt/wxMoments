<h1 align="center">📱 wxMoments</h1>
<p align="center"><b>微信数据导出备份工具</b></p>
<p align="center">朋友圈导出 · 公众号导出 · 聊天列表导出 · 聊天记录导出，全部保存到本地</p>

---

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 📄 **朋友圈导出** | 按好友 / 微信标签 / 时间筛选，导出 Markdown · HTML · PDF，图片、位置、点赞评论完整还原 |
| 🏷️ **微信标签分组** | 自动读取微信通讯录里已有的标签，与好友名单一样直接用；也能把几位好友存成自己的分组 |
| 📰 **公众号导出** | 单篇下载，或收割某公众号已点开过的全部文章后批量导出 |
| 👥 **聊天列表导出** | 好友与群聊分页签导出 CSV：好友含备注 / 昵称 / 微信号 / 地区 / 签名 / 置顶 / 免打扰；群聊含群名 / 备注 / 群主 / 成员名单 / 群公告 / 置顶 / 折叠。列可自由勾选 |
| 💬 **聊天记录导出** | 勾选私聊或群聊，按时间段 / 会话 / 内容类型筛选，导出微信风格离线 HTML · Markdown · PDF，图片、文件、语音（mp3）、公众号文章一并落盘 |

## 🚀 快速上手

```bash
git clone https://github.com/claudemt/wxMoments.git
cd wxMoments
run.bat
```

双击启动即可：首次会自动准备 `runtime/.venv` 并安装依赖，服务就绪后打开 `http://127.0.0.1:8756/`。再次双击会先停旧服务再启动新代码。

**特别提醒**：工具只能识别**这台电脑上曾经浏览过**的朋友圈：想补全就在微信里把朋友圈一路翻到底。同理，工具只能识别**这台电脑上曾经浏览过**的公众号文章：想补全就去把该作者下面的所有文章都点一遍。聊天记录读取的是本机聊天数据库：已经下载到本机的图片、文件、语音、视频会一起导出（图片按会话目录就近匹配，语音自动转成 mp3），只存在于微信服务器的媒体不会联网抓取。

## 💬 聊天记录导出

顶部第四个 Tab「聊天记录导出」，首次点「刷新」会解密本机聊天库（约几秒），之后即可浏览、预览、导出。

- **筛选**：时间段 + 会话范围（私聊 / 群聊）+ 会话名搜索 + 内容类型。时间与朋友圈一样填「开始 / 结束」日期（留空为不限），改动即时刷新；列表只列出该时间段内有消息的会话，导出也只包含这段时间的消息。列表只保留真正有消息的会话，顺序与微信侧栏一致：置顶的会话固定排在最前，置顶组内按最近一条消息的时间倒序；其余同样按时间倒序。微信里「折叠的群聊」默认不显示，需要时勾选「显示折叠群聊」（这类群通常只用来收通知，导出价值不大）。
- **内容类型**：默认全选（文字 / 图片 / 语音 / 视频 / 文件 / 链接 / 引用 / 合并转发 / 其他 / 系统消息），可以只勾其中几类，例如只导出图片和文件；一个都不选时会提示至少选一项。
- **预览**：点每行的「预览」进入聊天界面，默认加载最近 1000 条；「加载全部」可一次拉完该会话（几万条也支持，过程中可随时停止），也可以手动「加载更早消息」，支持消息内搜索与类型过滤。图片按原图显示（点击可看大图），文件按类型着色（PDF 红 / Word 蓝 / Excel 绿 / PPT 橙），链接、公众号文章与小程序都用可点击卡片呈现。
- **导出**：勾选会话后点「下载」，产物在 `output/聊天记录-<导出时间>/`：`index.html` 为会话索引，每个会话一份 `.html` + `.md` + `.pdf`，`media/` 存放图片、文件、语音、视频与链接封面，`articles/` 存放公众号文章，`manifest.json` 记录条数与媒体统计。导出完成的浮窗里点「打开目录」可直接定位到这个文件夹。
- **媒体**：已经下载到本机的图片、文件、语音、视频会一起导出（语音自动转 mp3，图片带缩略图与原图）；聊天页里的图片、文件、语音都按相对路径链接到本地文件，点开即可查看或播放。只在微信服务器上的媒体不会联网抓取，页面会显示占位提示。
- **公众号文章**：聊天里出现的公众号链接会单独存一份本地 `html` + `md`（`articles/` 下），聊天页的卡片直接指向本地文章，离线也能读；能联网且未被风控时会保存正文与配图，抓不到正文时退化为「标题 + 摘要 + 封面 + 原文链接」的离线快照页。之前用「公众号导出」保存过的同名文章会直接复制进来复用。
- **小程序**：只保留卡片信息（标题 / 来源 / 链接），标注「需在微信中打开」，不做离线还原。
- **观感**：HTML 与 PDF 都按微信聊天界面还原——左右气泡带小尖角、头像与昵称分层、日期胶囊、文件卡片、可点击播放的语音条、图片点开放大。HTML 支持搜索过滤、暗色模式与窄屏，也能直接打印；PDF 内置中文字体，不依赖浏览器。
- **说明**：公众号会话只承载文章推送，不参与聊天记录导出；导出的 HTML 完全离线可读，不依赖任何网络资源。

## 👥 聊天列表导出

顶部第三个 Tab「聊天列表导出」，顶部切换「好友 / 群聊」，点右侧「列」按钮勾选要导出的字段，再点左上角「导出好友 / 导出群聊」，得到一份 CSV（`output/好友列表-<时间>.csv` 或 `output/群聊列表-<时间>.csv`）。

- **好友**：备注名、实际名称、微信号、地区、个性签名、备注、用户ID、共同群数、置顶、免打扰、头像链接。列表按「置顶优先 + 名字拼音」排序。
- **群聊**：群名称、备注名、置顶、折叠、群主、成员数、群成员、群公告、免打扰、是否在群内、群ID、群头像。群成员读写自 `chatroom_member`，单元格里只预览前几位，导出时是完整名单（顿号分隔，自己在群里时显示为「我」）；群公告支持多行文本。未命名的群按微信的做法用前几位成员名代替。
- **筛选**：顶部的搜索框对好友匹配备注 / 昵称 / 微信号 / 用户ID，对群聊还会匹配群主与成员名，例如搜一个人名就能找出所有与他同群的群。
- 数据取自解密后的 `contact.db`（`contact` / `chat_room` / `chat_room_info_detail` / `chatroom_member`），需要先在「朋友圈导出」点一次「刷新」完成解密。

## 🧱 项目结构

```
run.bat                 一键启动（自建 runtime/.venv、装依赖、拉起服务）
config/                 config.example.json 复制为 config.json 后填 db_key
src/server.py           FastAPI 路由，只做参数校验与转发
src/wxmoments.py        朋友圈 / 好友 / 公众号的业务与渲染
src/wxchat.py           聊天记录读取、预览、导出（HTML·MD·PDF·媒体）
src/web/                index.html + style.css + app.js + chat.js（原生 JS）
src/wechat_decrypt_tool 解密、媒体索引与聊天库读取
src/wechat_download    公众号文章抓取与排版
tests/                  合成数据回归测试，不依赖微信进程与网络
runtime/                运行时产物（虚拟环境、解密快照、日志），不入库
output/                 导出结果，不入库
```

## 🧪 自检

```powershell
runtime\.venv\Scripts\python.exe tests\test_regressions.py
```

覆盖解密范围、任务取消、诊断游标、聊天分页游标、导出目录与 HTML 转义等关键路径；全部用合成数据，不需要登录微信，也不联网。
